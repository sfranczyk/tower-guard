# Tower Guard

A 2D side-view tower defense game in the browser. You are a stickman archer guarding the left keep against
waves of enemies marching in from the enemy keep on the right. Built with PixiJS 8 and TypeScript.

## Running

```bash
npm install
npm run dev
```

Then open http://localhost:8080. `npm run build` makes a production build in `dist/`.
